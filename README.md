# tidycreel slide decks

Rendered slide decks introducing [tidycreel](https://chrischizinski.com/tidycreel/),
an R package for creel survey design, estimation and reporting.

- **Overview** (`overview.html`): what tidycreel is and each step of a creel survey
- **Walkthrough** (`demo.html`): the same steps in depth, with most functions demonstrated

View them at <https://chrischizinski.github.io/tidycreel-decks/>.

This repository holds only the rendered, self-contained HTML files. They are built
from a separate private source with `just publish-decks`, which uses the public
variants of the slides.

Data: Nebraska Game and Parks Commission, Sherman Reservoir 2025.
